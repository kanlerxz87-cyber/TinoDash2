Standalone questions that gate Property A’s path

  1. Occupancy commitment: will any heir occupy ≥ 24 months? If yes → Prop 19 + §121 path jumps to the front. If no → Prop 19 is forfeited; rent is economically broken; sale leads.
  2. Market rent test: obtain 3 signed comparable leases (not Zestimate) for ≈ $8,000–$12,000/mo range; without them the letting paths are modeled as a floor only.
  3. Condition & inspections: general, roof, sewer lateral, termite/WDO, seismic retrofit (cripple wall?), solar warranty transferability — quotes in writing before listing.
  4. Sale-in-same-year sensitivity: model sale within 12 months of date of death vs later — capital gain ≈ $0 either way immediately; only property-tax carrying cost differs (≈ $71,400/yr if reassessed while held).
  5. §121 2-of-5 test (live-then-sell): must use A as principal residence 2 of 5 years before sale; exclusion $250,000 single / $500,000 MFJ; prior use of exclusion (2-yr lookback); ownership counts include trust period? — confirm with CPA.
  6. Like-kind (§1031): if heirs are investment-motivated and would redeploy into another CA rental, a 1031 defers gain — but A held for personal residence use does NOT qualify; only post-conversion rental use counts; take advice before signing any contract. See Open Questions.
