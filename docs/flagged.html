Irregularities / process notes

  • Privacy scrub: Git history inspected; only initial commit present before this session's work. No personal data found in pre-existing history. Public outputs anonymized and rounded to nearest $10.
  • Fetch limitations: Some official pages could not be fully extracted by automated tools in-session; official links are provided for manual verification. No values were fabricated to fill gaps.
  • Pages source changed (2026-11-25): the public site now serves the docs/ dashboard instead of the older root page. Confirm the new URL in the owner settings.
  • Official-source fetch limits: several official pages could not be fetched in-session (see Sources). Items relying on secondary excerpts are labeled as such.
  • Privacy scan: scripts/check_site.py scans the published pages for city/neighborhood names, ZIP codes, street addresses and parcel IDs. The scan is clean as of 2026-11-25. It does not catch values, so review numbers manually.
  • Model simplification: Scenario outputs are illustrative and not full CPA tax models. Tax-year-specific calculations must be reviewed by qualified professionals.
