Best path before implementing changes (review process)

  1. Resolve blockers first: Prop 19 eligibility, date-of-death valuation, estate inventory/prior gifts, TRA/property tax rate, Property A rent comps, inspection/capex.
  2. Run CPA same-year-sale sensitivity: include CA ordinary capital gains and 1% taxable-income-over-$1M surtax exposure.
  3. Update model with verified ranges: replace placeholders, keep rounding/anonymization.
  4. Rebuild and compare: see whether recommendation/ranking moved.
  5. Review suggestions: pick only changes that improve decision quality; record decision/date/reason.
  6. Implement selected changes on a branch/PR: re-verify sources, rebuild site, deploy.

Suggestions are advisory. Review before implementation.
