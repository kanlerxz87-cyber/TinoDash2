## Module controls

- No uploads, analytics, external fonts/scripts/styles, API calls, service workers, cookies, localStorage, sessionStorage or IndexedDB.
- No private values placed in URLs, Git, persistent browser storage or server requests by this module. Hypothetical numeric controls and generic suggestion reviews remain in tab memory; refreshing clears them.
- A restrictive content security policy prohibits script-initiated network connections, external code and form submission. Clicked official sources open without a referrer and with opener isolation.
- noindex/nofollow/noarchive are only crawler requests. They are not authentication, access control, anonymity or a way to remove existing caches. GitHub/hosting infrastructure can still log page requests; browser extensions and the user's own downloads are outside this app's control.
- Exports contain synthetic scenario values or generic review choices. Do not enter identifiers or household source records. The site rounds scenario dollars to $10 but **rounding is not anonymization**.
- Legal dollar constants are public official facts and can appear exactly when necessary. Displayed scenario and financial-export amounts use $10 increments. Actual household evidence remains blank, never inferred from an old assessment ratio or private hint.
- Generated build/PDF/CSV/XLSX and private/env/key directories are ignored. The build copies only named public files, never the repository, Git metadata, source records or the coordination board.

Use a separate encrypted matter file with an attorney/CPA/trustee for documents, inventories, appraisal, leases, quotes and signed household criteria/decisions. This module does not implement secure document handling or claim to have obtained such evidence.
